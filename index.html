Four bots

Party games for Telegram group chats. In Spy, Truth and Guess Who, type /newgame to start a round. In Riddle, type /emoji or /hangman.

  • Spy

    Word Wolf for groups. Everyone gets a secret word except the impostor, who bluffs through three rounds of one-word hints before the vote.

    Python, SQLiteCode on GitHub

  • Truth

    Two truths and a lie. One player submits three statements, the rest bet points on which is false. Streaks, bluffing bonuses and a leaderboard.

    Python, SQLiteCode on GitHub

  • Guess Who

    Players narrow down a hidden character or word with yes or no questions. Supports custom card packs.

    PythonCode on GitHub

  • Riddle

    Two games in one bot. Emoji Riddles posts an emoji clue and the first correct answer wins the round; in Hangman the group guesses letters or the whole word. Scores are kept per group and rounds survive a restart.

    Python, SQLiteCode on GitHub
